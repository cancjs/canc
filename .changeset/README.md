# Changesets

This folder holds changeset files, generated by running `npx changeset` (or the root `npm run
changeset` script) whenever a change needs a release note.

Every file in this folder (other than `config.json` and this README) is a committed file, part of
the repo history. Write changeset bodies the same way you would write any other committed content
in this repo: normal human prose, not the terse internal shorthand used in the project's own
planning docs. No internal identifiers, no references to internal-only paths or documents. If in
doubt about what belongs in a changeset body, write it as if it will be read only by someone
outside the project, because it will be: changeset bodies become the published changelog entries.

Full changesets documentation: https://github.com/changesets/changesets
